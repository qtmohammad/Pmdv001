# دعم RTL/LTR والترجمة الكاملة

## نظرة عامة

تم تحديث النظام بالكامل لدعم الانتقال السلس بين اللغة العربية (RTL) والإنجليزية (LTR) مع ترجمة كاملة لجميع النصوص والرسائل في التطبيق.

## الميزات المضافة

### 1. دعم RTL/LTR الكامل

- **تبديل اتجاه النص تلقائياً**: عند تبديل اللغة، يتغير اتجاه النص تلقائياً من اليمين لليسار (RTL) للعربية أو من اليسار لليمين (LTR) للإنجليزية
- **تخطيط متجاوب**: جميع المكونات تتكيف مع اتجاه النص بما في ذلك:
  - القوائم الجانبية (Sidebar)
  - الأيقونات والأزرار
  - حقول الإدخال
  - الجداول والبطاقات

### 2. الترجمة الكاملة

تم ترجمة جميع النصوص في التطبيق إلى العربية والإنجليزية، بما في ذلك:

#### صفحات المستخدم
- **صفحة تسجيل الدخول**: جميع العناصر والرسائل
- **صفحة التسجيل**: جميع الحقول والتنبيهات
- **صفحة الحساب**: معلومات المستخدم وتحديث كلمة المرور
- **صفحة منتجاتي**: إدارة التراخيص والدومينات

#### صفحات الإدارة
- **إضافة منتجات**: جميع الحقول والأوصاف
- **تعديل المنتجات**: كل العناصر التفاعلية
- **إدارة المشترين**: الجداول والحوارات

#### الرسائل والإشعارات
- **رسائل النجاح**: جميع رسائل التأكيد
- **رسائل الخطأ**: كل رسائل الأخطاء
- **التنبيهات**: جميع التنبيهات والتحذيرات

### 3. التحسينات التقنية

#### في ملف `LanguageContext.tsx`
تم إضافة أكثر من 100 مفتاح ترجمة جديد يغطي:
- العناوين والأوصاف
- الأزرار والإجراءات
- رسائل النجاح والخطأ
- النماذج والحقول
- الجداول والقوائم

#### في ملف `globals.css`
تم إضافة قواعد CSS خاصة بدعم RTL:
```css
[dir="rtl"] {
  direction: rtl;
}

/* دعم خاص للأيقونات والحقول */
[dir="rtl"] .rtl\:left-auto { ... }
[dir="rtl"] .rtl\:right-3 { ... }
[dir="rtl"] .rtl\:pr-10 { ... }
[dir="rtl"] .rtl\:pl-3 { ... }
```

#### في جميع مكونات React
تم تحديث جميع المكونات لاستخدام:
- `t()` للترجمة بدلاً من النصوص الثابتة
- `isRTL` لتحديد اتجاه الأيقونات والعناصر
- `dir="ltr"` للحقول التي يجب أن تبقى LTR (البريد الإلكتروني، الأسعار، إلخ)

## الاستخدام

### تبديل اللغة
1. انقر على أيقونة اللغة (🌐) في شريط الأدوات العلوي
2. سيتم تبديل اللغة تلقائياً بين العربية والإنجليزية
3. سيتم حفظ اللغة المختارة في localStorage

### الحقول الخاصة
بعض الحقول تبقى دائماً LTR حتى في الوضع العربي:
- عناوين البريد الإلكتروني
- معرفات التطبيقات (App IDs)
- أسماء الدومينات
- الأسعار

## الملاحظات الهامة

### 1. الاتساق
- جميع النصوص تستخدم نظام الترجمة `t(key)`
- لا توجد نصوص ثابتة في الكود
- جميع الرسائل والإشعارات مترجمة

### 2. الأداء
- الترجمات محملة مسبقاً في الذاكرة
- تبديل اللغة فوري بدون تأخير
- حفظ تلقائي للتفضيلات

### 3. التوسعة
لإضافة ترجمة جديدة:
```typescript
// في LanguageContext.tsx
const translations: Translations = {
  newKey: { ar: 'النص العربي', en: 'English Text' }
};

// في المكون
{t('newKey')}
```
