📋 الترتيب الصحيح:
────────────────────────────────────────────────────────────────────────────

   الخطوة 1️⃣: إصلاح الـ Imports (⚠️ مهم جداً!)
   ──────────────────────────────────────────
   npm run fix-imports
   
   أو:
   node fix-imports.js
   
   ⏰ سيستغرق 5 ثوانٍ فقط
   ✅ سيُصلح 52 ملفاً تلقائياً


   الخطوة 2️⃣: تثبيت الحزم
   ──────────────────────
   npm install
   
   ⏰ سيستغرق 2-5 دقائق
   ✅ سيُثبت 40+ حزمة


   الخطوة 3️⃣: إعداد Firebase
   ─────────────────────────
   1. انسخ ملف: .env.example
   2. أعد تسميته إلى: .env
   3. افتح .env وضع بيانات Firebase
   
   📖 راجع: FIREBASE_SETUP.md للتفاصيل


   الخطوة 4️⃣: تشغيل المشروع
   ───────────────────────
   npm run dev
   
   ✅ سيفتح على: http://localhost:3000

⚠️ مشاكل شائعة وحلولها:
────────────────────────────────────────────────────────────────────────────

   ❌ "Cannot find module 'package@1.2.3'"
      ✅ الحل: npm run fix-imports

   ❌ "Port 3000 is already in use"
      ✅ الحل: npm run dev -- --port 3001

   ❌ Firebase لا يعمل
      ✅ الحل: تأكد من ملف .env وبياناته

   ❌ Firestore Index Error
      ✅ الحل: افتح FIX_INDEX_ERROR.html

   ❌ "npm: command not found"
      ✅ الحل: ثبت Node.js من nodejs.org
