# الأخطاء الشائعة والحلول السريعة

## 🚨 دليل الحلول السريعة

---

### 1️⃣ خطأ: "Permission Denied" أو "Missing or insufficient permissions"

**السبب**: قواعد Firestore غير مُعدّة

**الحل السريع** (دقيقة واحدة):
```
1. افتح Firebase Console → Firestore Database → Rules
2. انسخ المحتوى من ملف firebase-rules-ready.txt
3. الصق في محرر القواعد
4. اضغط Publish
5. أعد تحميل الصفحة
```

**التفاصيل**: راجع `FIRESTORE_RULES.md`

---

### 2️⃣ خطأ: "Cannot parse Firebase url"

**السبب**: Realtime Database غير مُنشأ أو URL خاطئ

**الحل السريع**:
```
1. Firebase Console → Realtime Database → Create Database
2. انسخ الـ URL من أعلى الصفحة
3. افتح /lib/firebase.ts
4. حدّث databaseURL بالـ URL الصحيح
5. احفظ الملف
```

**مثال على URL صحيح**:
```
https://mobhm-l-default-rtdb.firebaseio.com
```

**التفاصيل**: راجع `TROUBLESHOOTING.md`

---

### 3️⃣ لا أرى "لوحة الإدارة" في القائمة

**السبب**: الحساب غير مُعيّن كمدير

**الحل - الطريقة 1** (من Firestore):
```
1. سجل دخول أولاً
2. Firebase Console → Firestore → buyers
3. افتح مستند حسابك
4. أضف حقل: isAdmin = true (boolean)
5. احفظ
6. سجل خروج وسجل دخول مجدداً
```

**الحل - الطريقة 2** (من الكود):
```
1. افتح Console (F12)
2. اكتب: firebase.auth().currentUser.uid
3. انسخ الـ UID
4. افتح /contexts/AuthContext.tsx
5. السطر 51: أضف الـ UID في ADMIN_UIDS
6. احفظ الملف
```

---

### 4️⃣ خطأ: "Email not authorized"

**السبب**: البريد غير موجود في قائمة المشترين

**الحل**:
```
1. سجل دخول كمدير أولاً
2. اذهب إلى "إدارة المشترين"
3. اضغط "إضافة مشتري"
4. أضف البريد الإلكتروني
5. الآن يمكن للمشتري التسجيل بهذا البريد
```

---

### 5️⃣ لا توجد منتجات في "منتجاتي"

**السبب**: لم يتم تعيين منتجات لهذا المشتري

**الحل**:
```
1. سجل دخول كمدير
2. اذهب إلى "إدارة المشترين"
3. اختر المشتري
4. اضغط "Assign"
5. اختر المنتج والخطة
6. احفظ
7. سجل دخول بحساب المشتري وتحقق
```

---

### 6️⃣ خطأ عند إضافة ترخيص (App ID أو Domain)

**السبب 1**: Realtime Database غير مُعدّ

**الحل**: راجع الخطأ رقم 2 أعلاه

**السبب 2**: قواعد Realtime Database خاطئة

**الحل**:
```
1. Firebase Console → Realtime Database → Rules
2. انسخ قواعد Realtime DB من firebase-rules-ready.txt
3. الصق في محرر القواعد
4. اضغط Publish
```

---

### 7️⃣ رسالة "Maximum X domains allowed"

**السبب**: وصلت للحد الأقصى المسموح به

**الحل**:
```
لزيادة العدد:
1. سجل دخول كمدير
2. إدارة المشترين → اختر المشتري
3. ابحث عن المنتج في قائمته
4. احذف المنتج وأعد تعيينه مع عدد دومينات أكبر
```

**بديل**: احذف دومين قديم لإضافة جديد

---

### 8️⃣ الواجهة باللغة الخاطئة

**الحل السريع**:
```
اضغط زر 🌐 في أعلى الصفحة للتبديل بين العربية والإنجليزية
```

---

### 9️⃣ الوضع المظلم/الفاتح لا يعمل

**الحل**:
```
اضغط زر 🌙/☀️ في أعلى الصفحة
التفضيلات تُحفظ تلقائياً في المتصفح
```

---

### 🔟 خطأ: "Network Error" أو "Failed to fetch"

**الأسباب المحتملة**:

1. **لا يوجد اتصال بالإنترنت**
   - تحقق من اتصالك

2. **API Key خاطئ**
   - راجع `/lib/firebase.ts`
   - تحقق من `apiKey` في Firebase Console

3. **النطاق غير مُصرّح**
   - Firebase Console → Authentication → Settings
   - تحقق من Authorized domains

---

## 🔍 التشخيص العام

عند ظهور أي خطأ:

### الخطوة 1: افتح Console
```
اضغط F12 في المتصفح
تحقق من تبويب Console للأخطاء
```

### الخطوة 2: ابحث عن الخطأ
```
اقرأ رسالة الخطأ كاملة
ابحث عنها في هذا الملف
```

### الخطوة 3: جرب الحل السريع
```
طبق الحل المذكور
أعد تحميل الصفحة
```

### الخطوة 4: التفاصيل
```
إذا لم ينجح الحل السريع:
راجع الملف المُشار إليه في "التفاصيل"
```

## 💡 نصائح سريعة

### عند التطوير:
- استخدم Test Mode في Firestore لسهولة الاختبار
- تحقق من Console باستمرار
- سجل خروج ودخول عند تغيير الصلاحيات

### عند الإنتاج:
- غيّر إلى Production Mode
- راجع Security Rules جيداً
- لا تشارك Firebase config علناً

### للمدراء:
- احتفظ بنسخة احتياطية من Firestore
- راقب الاستخدام في Firebase Console
- حدّث قواعد الأمان بانتظام

## ✅ الإعداد الصحيح

عند انتهاء الإعداد بنجاح، يجب أن:

✓ تسجيل الدخول يعمل بدون أخطاء
✓ صفحة "منتجاتي" تُحمّل بدون أخطاء
✓ إضافة التراخيص تعمل بنجاح
✓ لا توجد رسائل خطأ في Console
✓ المدراء يرون "لوحة الإدارة"

إذا تحقق كل ما سبق، فالإعداد مكتمل! 🎉
